# demo-app

A tiny collection of string helper functions. Small, dependency-free, and easy to extend.

## Usage

```python
from stringutils import slugify, truncate

slugify("Hello, World!")        # -> "hello-world"
truncate("a long sentence", 6)  # -> "a long…"
```
